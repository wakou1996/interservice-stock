Serveur de données ADMIN

Un seul serveur garde les données, que l'on se connecte depuis un téléphone (APK) ou un ordinateur. Accès permanent via l'adresse ci-dessous.

Mise en place (5 minutes)

  1. PC serveur toujours allumé → notez son IP (ipconfig).
  2. Copiez ce fichier dans \\SERVEUR\Stock\ et lancez python -m http.server 8000 dans ce dossier.
  3. Téléphones (APK) + PC : ouvrez http://192.168.1.10:8000 — même base, accès à tout moment.
  4. Synchronisation : exportez le fichier de sync et rechargez-le sur l'autre appareil si le réseau coupe.

  1. Android Chrome : menu ⋮ → Installer l'application / Ajouter à l'écran d'accueil.
