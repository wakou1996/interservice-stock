# INTER SERVICE Audit Industriel — Application web

Application web/PWA d'inventaire industriel construite à partir du fichier HTML fourni.

## Lancer localement

```bash
npm start
```

Puis ouvrir `http://localhost:8000`.

## Comptes de démonstration

- Administrateur : `admin` / `admin123`
- CIMFIG : `magasin.fig` / `fig2026`
- Yaoundé : `magasin.yde` / `yde2026`
- Douala : `magasin.dla` / `dla2026`

## Déploiement

Le dossier est statique et peut être déployé sur Netlify, Vercel ou un hébergement web classique. Les données de cette version sont enregistrées dans le stockage local du navigateur.
